# Domain Model

## OPL App

OPL App — веб-приложение для поддержки операционных процессов.

## Collections

Коллекции позволяют пользователю группировать объекты приложения.

Базовые сценарии:

1. Создать коллекцию.
2. Посмотреть список коллекций.
3. Открыть коллекцию.
4. Добавить объект в коллекцию.
5. Удалить объект из коллекции.
6. Переименовать коллекцию.

Коллекция не должна дублировать объект целиком. Элемент коллекции должен ссылаться на объект приложения.

Теги изолированы в рамках коллекции: каждый тег принадлежит ровно одной коллекции (`collection_id`). Глобальный пул тегов больше не используется для новых данных.

## Shift Journal

Сменный журнал фиксирует состояние и события смены.

Основные разделы:

1. Открытие смены
2. События смены
3. Закрытие смены

## Shift tasks

Задачи внутри смены:

- accepted_from_previous_shift;
- created_current_shift;
- completed_current_shift;
- handed_over_to_next_shift;
- cancelled.

Физическое удаление задач не используется.
